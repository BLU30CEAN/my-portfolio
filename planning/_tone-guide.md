# Tone Guide — BLU30CEAN / EJ

> 한 줄 요약: **"실험으로 증명하는 사람"이라는 사실이 모든 화면에서 은근히 새어 나오게.**

## 1. Persona

- **누구인가**: 5년차 풀스택 / AI 서비스 엔지니어 EJ.
- **이야기 구조**: 슬라이드가 아니라 **돌아가는 데모**로 자신을 설명한다.
- **반대 페르소나(피해야 할 톤)**: 화려한 자기소개, "5년차 시니어급" 같은 자랑형 문구, 이모지 폭발, 자기 칭찬.

## 2. Voice — 말투 규칙

| 항목 | 규칙 |
| --- | --- |
| 인칭 | "저는" 대신 **"이 프로젝트는"** 으로 시작. 주인공은 결과물. |
| 길이 | 한 문장 60자 이내. 두 문장 이상은 줄바꿈으로 분리. |
| 동사 | "구현했습니다" 대신 **"붙였다 / 깎았다 / 비틀어봤다 / 실험했다"**. 능동적·물리적 동사. |
| 형용사 | 형용사는 최대 1개. "정말, 매우, 가장" 같은 부사 금지. |
| 종결 | 한국어는 **반말체 + 단정형** ("했다 / 만든다 / 풀어본다"). 영문 카피는 sentence case. |
| 이모지 | UI 안에서는 **카테고리 표식 1개**만 (🃏 ⚾ 🐰 🥕). 본문에서 금지. |
| 숫자 | 막연한 수식 대신 "5년", "20+ 스택" 처럼 단위·범위를 박는다. |

### 예시 변환

| Before (현재) | After (새 톤) |
| --- | --- |
| "🎮 게임하기" | "Play" / "지금 던지기" |
| "✨ 주요 특징" | "이 실험에서 뭘 풀었나" |
| "🚀 다양한 기술을 활용한 프로젝트들" | "5개 실험 · 5개 실패 · 5개 학습" |
| "직관적인 UI/UX로 누구나 쉽게..." | "초보자가 30초 안에 첫 분석을 본다. 그게 전부다." |

### 시각 규칙

1. **이중 폰트**: 본문은 Inter/Pretendard, **태그·숫자·코드는 모노**. 모노가 보일 때마다 "엔지니어가 만든 화면" 신호.
2. **그라데이션**은 3종만: `cobalt`(기본), `experiment`(코발트→마젠타, 실험 라벨), `playful`(시안→라임, 게임 CTA).
3. **모서리**: 카드 `--bc-r-lg`(20px), 버튼 `--bc-r-pill`. 직사각형 카드 금지.
4. **그림자**: 평면 + `--bc-sh-glow` 호버. 두꺼운 drop shadow 금지.
5. **모션**: 240ms `--bc-ease-out`. 스프링은 게임 CTA에만.

## 4. Layout Rhythm

- 모든 페이지는 **헤더 → 한 줄 선언문 → 카드 그리드 → 푸터** 구조.
- 한 줄 선언문은 **모노 폰트**로, 마치 터미널 명령처럼 보이게.
  ```
  $ ej --build ideas --ship-broken
  ```
- 페이지 첫 화면에 "실험중"인 항목이 1개 이상 보여야 한다 (마젠타 칩 `bc-tag-experiment`).

## 6. Anti-patterns (절대 하지 말 것)

1. 한 화면에 그라데이션 4종 이상.
2. "최고 / 완벽 / 혁신" 같은 자기 평가 형용사.
3. CTA 버튼 4개 이상 — **결정을 강요하지 않는 UI는 게으른 UI**.
4. 이모지 헤더 (`🚀 프로젝트` 금지) — 이모지는 라벨, 헤더는 글로.
5. 한국어/영어 혼용 슬로건 (`✨ Awesome 결과물`) — 한 언어로.
6. "곧 다시 활성화될 예정입니다" 같은 미완의 변명. 제거하든 새로 만들든 한다.
